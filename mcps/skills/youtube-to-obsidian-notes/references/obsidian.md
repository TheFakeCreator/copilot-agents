# Obsidian Integration

This reference describes defaults only. Existing vault rules take precedence.

## Inspect before writing

Check relevant:

- global instructions
- folder instructions
- templates
- neighboring notes
- MOCs
- properties
- tags
- naming conventions
- linking patterns

## Existing notes

Before creating a note, determine whether:

- the exact topic already exists
- a related note should be extended
- an existing MOC should be updated
- the vault already has a preferred location

Avoid duplicate knowledge.

## Metadata

Reuse the vault's established property names and value conventions.

Do not invent a new metadata schema when one already exists.

Common metadata may include:

- title
- source
- source URL
- date
- topic
- tags
- type

Only include properties that fit the vault.

## Links

Prefer meaningful Wikilinks over link spam.

Link:

- prerequisites
- related concepts
- established topics
- relevant MOCs
- important tools/technologies

Do not link every word.

Do not invent links to nonexistent notes unless the vault workflow intentionally uses placeholder links.

## Tags

Follow existing tag conventions.

Do not create large numbers of granular tags simply because the source mentions many subjects.

## Callouts

Use callouts only when they improve scanning or emphasis.

Useful categories may include:

- Note
- Important
- Warning
- Tip
- Example
- Question

Use the vault's own callout conventions if different.

## Tables

Use tables for genuine comparisons or structured attributes.

Do not force narrative explanations into tables.

## Code

Use fenced code blocks for code.

Preserve important code examples from the source when they are part of the learning objective.

Keep long code excerpts only when they are necessary for understanding.

## Mathematics

Use LaTeX for mathematical expressions where appropriate.

Preserve variables, equations, assumptions, and units accurately.

## Mermaid

Use only when a visual relationship is easier to understand as a diagram.

Validate Mermaid syntax.

Do not make a diagram when a few bullets are clearer.
