# Note Patterns

Choose the pattern that matches the content.

## Concept / Theory

```markdown
# Topic

## Overview

## Core Idea

## Key Concepts

## How It Works

## Why It Matters

## Example from the Video

## Mental Model

## Caveats

## Common Misconceptions

## Active Recall

## Related Notes
```

## Technical Tutorial

```markdown
# Topic

## Goal

## Prerequisites

## Core Concepts

## Architecture / Flow

## Step-by-Step

## Example

## Code / Implementation

## Common Errors

## Practical Takeaways

## Active Recall

## Related Notes
```

## Comparison

```markdown
# X vs Y

## Overview

## X

## Y

## Key Differences

| Aspect | X | Y |
|---|---|---|

## When Each Applies

## Example

## Active Recall

## Related Notes
```

## Process / Workflow

```markdown
# Process

## Purpose

## Inputs

## Flow

## Mermaid

## Step-by-Step

## Failure Cases

## Example

## Active Recall
```

## Lecture / Educational Video

Use a concept hierarchy:

```markdown
# Topic

## Overview

## Core Idea

## 1. Major Concept

### Explanation

### Example

## 2. Major Concept

### Explanation

### Example

## Connections

## Key Takeaways

## Active Recall

## Related Notes
```

Do not force all sections into every note.

The structure should follow the knowledge.
